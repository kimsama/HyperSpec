# File Structure

## Repository Layout

```
HyperSpec/
├── package.json                   # npm package config, bin entry, scripts
├── tsconfig.json                  # TypeScript compiler options (ES2022, ESM, strict)
├── tsup.config.ts                 # Bundles src/cli/index.ts -> dist/index.js (ESM, node20)
├── vitest.config.ts               # Test runner config (node env, tests/**/\*.test.ts)
├── .gitignore                     # node_modules/, dist/, *.tsbuildinfo
│
├── bin/
│   └── hyperspec.js               # CLI shim: #!/usr/bin/env node, imports dist/index.js
│
├── src/
│   ├── cli/                       # CLI commands (TypeScript -> compiled to dist/)
│   │   ├── index.ts               # Commander program setup, all command registrations
│   │   ├── init.ts                # `hyperspec init` — scaffolds docs/html-spec/ in user project
│   │   ├── index-cmd.ts           # `hyperspec index` — generates manifest.json from HTML files
│   │   ├── setup.ts               # `hyperspec setup` — interactive config wizard
│   │   ├── serve.ts               # `hyperspec serve` — HTTP server + SSE live reload
│   │   ├── translate.ts           # `hyperspec translate` — prints translation prompt for agent
│   │   └── install.ts             # `hyperspec install|update` — copies skill files per agent
│   │
│   └── lib/                       # Shared library modules (used by CLI commands)
│       ├── config.ts              # HyperSpecConfig type, load/save/defaults
│       ├── manifest.ts            # HTML metadata extraction, manifest generation
│       └── scanner.ts             # CSS/JS component scanning
│
├── assets/                        # Browser assets (vanilla JS/CSS, no build step)
│   ├── annotate.js                # Annotation IIFE (~710 lines)
│   │                              #   Selection detection, floating toolbar, popover,
│   │                              #   side panel, localStorage, export feedback JSON

│   │                              #   Toolbar, popover, highlights (4 color types),
│   │                              #   side panel, export button, toast, responsive

│   │                              #   CSS variables (--hs-*), reset, headings, code, tables
│   └── portal/

│   │       └── hyperspec-translate.md # /hyperspec-translate — translate HTML to locale
│   ├── codex/
│   │   └── AGENTS.md              # Same principles adapted for Codex convention
│   └── antigravity/
│       └── skill.md               # Concise skill for Antigravity agents
│
├── tests/
│   ├── lib/
│   │   ├── config.test.ts         # 4 tests: defaults, round-trip, missing file, partial merge
│   │   ├── manifest.test.ts       # 5 tests: extract metadata, generate manifest, translations
│   │   └── scanner.test.ts        # 7 tests: CSS parsing, JS parsing, markdown output
│   ├── cli/

│   │   └── index-cmd.test.ts      # 2 tests: manifest from HTML, empty manifest

│       ├── annotation-test.html   # Manual browser test page for annotation module
```

## User Project Output Structure

When a user runs `hyperspec init`, this structure is created in their project:

```
project/
└── docs/html-spec/
    ├── index.html                 # Portal page (copied from assets/portal/index.html)
    ├── manifest.json              # Document index (generated by `hyperspec index`)
    ├── hyperspec.config.json      # Project configuration
    ├── assets/                    # Copied from HyperSpec package
    │   ├── annotate.js
    │   ├── annotate.css
    │   ├── base.css
    │   ├── portal.js
    │   └── portal.css
    ├── components/                # Empty; populated by `hyperspec setup`
    │   ├── components.css         # (after setup with component library)
    │   ├── components.js          # (after setup with component library)
    │   └── COMPONENT-REFERENCE.md # (auto-generated by scanner)
    └── htmls/                     # Generated HTML documents
        ├── auth-spec.html         # (example)
        ├── api-review.html        # (example)
        └── ko/                    # Korean translations
            └── auth-spec.html     # (example)
```

## Key Dependencies

| Package | Version | Purpose |
|---------|---------|---------|
| commander | ^14.x | CLI framework — command parsing, options, help |
| chokidar | ^5.x | File watching for `hyperspec serve` live reload |
| typescript | ^6.x | Dev: type checking |
| tsup | ^8.x | Dev: CLI bundling (src/ -> dist/) |
| vitest | ^4.x | Dev: test runner |
| @types/node | ^25.x | Dev: Node.js type definitions |
