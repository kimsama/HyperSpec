Production

Development

typescript ^6.x Type checking for CLI source code (src/)
tsup ^8.x CLI bundling: src/cli/index.ts → dist/index.js (ESM, node20)
vitest ^4.x Test runner — 24 tests across 6 files, node environment
@types/node ^25.x Node.js type definitions for TypeScript
Zero runtime deps for output. The generated HTML uses only vanilla JS/CSS — no frameworks, no CDN, no build tools needed by end users.
